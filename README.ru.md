## 🚀 Ключевые преимущества и фичи

### 1. Извилистая настольная дорожка уроков (Serpentine Roadmap)
- **Игровой путь:** Уроки выстроены по извилистой траектории с разделителями этапов, фишкой ученика с аватаром (`🦊`) и светящимися связями.
- **Финишная цель с прогрессом:** Лаконичный флаг финиша со счётчиком (`Пройдено X из Y уроков · осталось Z`). **Никаких пиратских сундуков** и визуального шума.
- **Входная диагностика:** Интеллектуальный тест из 8 вопросов детерминированно выявляет уровень студента (*Beginner*, *Elementary*, *Pre-Intermediate*) и открывает персональный маршрут.

### 2. Мульти-степпер проверки знаний (3+ упражнения на урок)
- **Не менее 3 различных заданий на каждый урок:** Тесты с вариантами ответов, предсказание вывода кода, заполнение пропусков, перевод.
- **Интерактивный степпер:** Студент переключается между упражнениями с наглядными индикаторами статуса (текущее, решено, ожидает).
- **Мгновенный отклик:** Детальные объяснения, умные подсказки с маскотом и аудио-реакции.

### 3. Интерактивные разборы кода и песочницы
- **Декомпозиция функций Python:** Цветные интерактивные блоки для каждого элемента сигнатуры (`def`, имя функции, параметры, тайпхинты, docstring, тело, `return`).
- **Живая HTML/CSS песочница:** Двухвкладочный интерфейс с подсветкой кода и живым интерактивным окном рендера flexbox-компонентов.

## 🎨 Визуальный дизайн и система тем

Kivora разработана на базе двухуровневой контрастной дизайн-системы:

| Параметр | Светлая тема Apple (`light`) | Тёмная тема Linear (`dark`) |
| :--- | :--- | :--- |
| **Фон** | Свежий тёплый оттенок `#FBFBFD` | Глубокий обсидиановый сланцевый `#0D0D12` |
| **Поверхности** | Полупрозрачное матовое стекло `#FFFFFF` | Дымчатый акрил `#16161F` / `#1C1C28` |
| **Акцентный цвет** | Королевский индиго `#6366F1` | Неоновый электро-индиго `#818CF8` |
| **Типографика** | Чёткий тёмный угольный `#0F172A` | Контрастный белый `#F8FAFC` |
| **Границы** | Тончайшие линии `rgba(0,0,0,0.08)` | Стеклянные грани `rgba(255,255,255,0.1)` |

*Переключение тем происходит мгновенно в 1 клик через навбар или настройки профиля.*

## 🔊 Процедурный аудио-движок (Web Audio API)

Все звуковые эффекты в Kivora генерируются **на лету программным синтезом** через стандартный браузерный `AudioContext`:
- **0 внешних аудиофайлов:** Никаких скачиваний MP3/WAV, нулевая задержка сети, отсутствие риска битых ссылок.
- **100% легальность и чистота:** Ноль заимствованных звуков. Спецификация и открытая лицензия MIT/CC0 зафиксированы в [`public/audio/ATTRIBUTION.md`](./public/audio/ATTRIBUTION.md).
- **Синтезированные эффекты:**
  - `answer.correct`: Восходящее мажорное трезвучие (до 523 Гц → ми 659 Гц → соль 784 Гц) с мягким фильтром низких частот (~0.35 сек).
  - `answer.incorrect`: Мягкий комичный нисходящий перелив маримбы (ре 293 Гц → си 246 Гц → соль-диез 207 Гц) с тёплым тембром. Дружелюбно, без насмешек и наказания (~0.26 сек).
  - `lesson.complete`: Праздничная фанфара достижения (до 523 Гц → ми 659 Гц → соль 784 Гц → до 1046 Гц) (~0.55 сек).
  - `checkpoint.unlock`: Искрящийся колокольный перезвон (ми 1318 Гц + си 1975 Гц) (~0.32 сек).
- **Управление звуком:** Кнопка отключения звука, плавный слайдер громкости и кнопка «Тест звука» доступны в навигации, на дорожке курса и в настройках профиля. Состояние сохраняется в `localStorage`.

## 🗣️ Озвучивание уроков и синтез речи (Web Speech API)

В каждом уроке присутствует кнопка **«Прослушать объяснение»** на базе **Web Speech API** (`window.speechSynthesis`):
- **Чистый поток речи:** Специальный алгоритмический очиститель вырезает блоки кода, знаки разметки и спецсимволы, чтобы синтезатор читал понятный живой текст.
- **Управление воспроизведением:** Кнопки Старт, Пауза, Продолжить и Стоп с анимированной пульсирующей звуковой волной.
- **Выбор скорости:** Переключение скорости чтения между `0.8x`, `1.0x` и `1.2x`.
- **Автоопределение голосов устройства:** Система автоматически подбирает лучший установленный голос для языка интерфейса (`ru-RU`, `ky-KG`, `en-US`). Если голос в ОС отсутствует, выводится вежливое уведомление.
- **Приглушение звуков (Audio Ducking):** Игровые звуки автоматически приглушаются на 60% во время чтения теории.
- **Безопасная навигация:** Озвучивание автоматически останавливается при переходе на другой урок.

## 🦊 Оригинальный векторный маскот «Киви» (Kivi)

Киви — это авторский **100% векторный SVG-маскот** платформы (очаровательная птичка киви с выразительными глазами и перьевым чубчиком). Киви реагирует на успехи ученика и сопровождает репликами на русском, кыргызском и английском языках:

| Настроение | Визуальный образ | Когда появляется |
| :--- | :--- | :--- |
| **`celebrate`** | Звёздочки в глазах, академическая шапочка выпускника, победный жест | При правильном ответе на вопрос |
| **`encourage`** | Тёплая улыбка, сияющее сердечко, дружелюбная поза поддержки | При неверном ответе (подбадривание без стресса) |
| **`thinking`** | Задумчиво подпирает клюв крылышком, светящаяся лампочка | Внутри карточки подсказки к заданию |
| **`champion`** | Золотая медаль чемпиона с лавровой лентой, поза триумфа | При успешном завершении всех заданий урока |

## 📚 Каталог курсов и углублённый трек китайского языка

Платформа включает **15 готовых курсов** по программированию, языкам и гибким навыкам с **полной поддержкой трёх языков (RU / KY / EN)**:

### 🇨🇳 Полный вводный курс китайского языка (`chinese-intro`):
- **Этап 1: Пиньинь и 4 тона (Пиньинь жана 4 тон)**
  - `zh-s1-l1`: Четыре тона китайского языка (mā, má, mǎ, mà и нейтральный тон)
  - `zh-s1-l2`: Инициали и финали в пиньине (придыхательные согласные b/p, гласный ü)
  - `zh-s1-l3`: Модуляция тонов (сандхи) и правила чтения (3+3→2+3, изменения bù и yī)
- **Этап 2: Приветствия и числа (Саламдашуу жана сандар)**
  - `zh-s2-l1`: Приветствия и слова вежливости (Nǐ hǎo, Nín hǎo, Xièxie, Zàijiàn)
  - `zh-s2-l2`: Счёт от 1 до 10 и составные числа (yī...shí, формулы сложения)
  - `zh-s2-l3`: Вопросы о делах и вежливые ответы (Nǐ hǎo ma?, Duìbuqǐ, Méi guānxi)
- **Этап 3: Знакомство и первые иероглифы (Таанышуу жана алгачкы иероглифтер)**
  - `zh-s3-l1`: Представление по имени (Wǒ jiào..., Wǒ shì xuésheng, Nǐ ne?)
  - `zh-s3-l2`: Базовые ключи и первые пиктограммы (人, 口, 日, 月, 木, 明)
  - `zh-s3-l3`: Итоговый мини-диалог знакомства (живой диалог Ли Мина и Елены)

*Каждый из 9 уроков содержит по 3 проверочных задания, подробную теорию и 100% аутентичные переводы на русский и кыргызский языки.*

## 💻 Установка и локальный запуск

### Требования
- Node.js 18.18+ или 20+
- npm или pnpm

### 1. Клонирование репозитория
```bash
git clone https://github.com/ad1llov-design/KONFERENS.git
cd KONFERENS
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск сервера разработки
```bash
npm run dev
```
Откройте **[http://localhost:3000](http://localhost:3000)** в браузере.  
*Платформа работает мгновенно в автономном Demo-режиме без обязательной настройки внешних ключей.*

### 4. Проверка сборки и линтинга
```bash
npx tsc --noEmit     # Проверка строгой типизации TypeScript (0 ошибок)
npm run lint         # Проверка ESLint (0 ошибок)
npm run build        # Продакшн-сборка Next.js (27 статических/динамических страниц)
```

## 🎤 Сценарий для демонстрации на конференции

1. **Главная страница (`/`):**
   - Переключите язык: покажите мгновенную смену между **Русским**, **Кыргызча** и **English**.
   - Переключите тему: продемонстрируйте светлую тему Apple и тёмную тему Linear.
2. **Панель управления звуком:**
   - Нажмите на значок динамика в верхнем меню.
   - Отрегулируйте громкость и нажмите **«Тест звука»**, чтобы услышать синтезированный аккорд.
3. **Игровая дорожка курса (`/courses/chinese-intro/learn`):**
   - Продемонстрируйте извилистую настольную дорожку из 3 этапов и 9 уроков.
   - Покажите фишку ученика с аватаром (`🦊`) и флаг финишной цели.
   - Кликните по активному узлу и обратите внимание на кристальный перезвон `playCheckpoint()`.
4. **Интерактивный урок (`/courses/chinese-intro/learn/zh-s1-l1`):**
   - Нажмите **«Прослушать объяснение» / «Түшүндүрмөнү угуу»** для демонстрации синтеза речи.
   - Измените скорость озвучивания (`0.8x`, `1.0x`, `1.2x`).
   - Перейдите на вкладку **«Задание»**: покажите 3-шаговый степпер (`1`, `2`, `3`).
   - Выберите неверный ответ → воспроизводится мягкий комичный перелив маримбы, появляется Киви в образе `encourage`.
   - Выберите верный ответ → звучит торжественный мажорный аккорд, Киви в образе `celebrate`.
   - Пройдите все 3 задания → звучит фанфара завершения, Киви с золотой медалью `champion`.
5. **Интерактивный код и диагностика:**
   - Откройте урок Python `py-s3-l1` для показа интерактивного разбора ключевого слова `def`.
   - Откройте урок Web Dev `web-s1-l1` для демонстрации живой песочницы HTML/CSS.
